# Swift Logistics

Full-stack parcel booking and delivery tracking platform.

## 🚀 Features

- User registration and authentication
- Admin approval workflow
- Parcel booking and management
- Delivery status tracking
- Public parcel tracking
- Search, filtering, sorting and pagination
- CSV export
- User management
- District → Sub-district → Thana selection

## 🛠️ Tech Stack

### Frontend
- React
- Tailwind CSS
- Axios

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT
- Pydantic

## 📁 Project Structure

frontend/
→ React frontend application

backend/
→ FastAPI backend API
